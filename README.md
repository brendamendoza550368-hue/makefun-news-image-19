One image that sums up the world news of **Thursday 19 November 2026**: the historic Trump-Xi-Putin three-way summit in Shenzhen, the worldwide launch of GTA VI after a 13-year wait (99 on Metacritic), Trump's dirty-bomb warning to Iran as missiles fly in the Gulf, the World Court ruling that Myanmar committed state-sponsored genocide against the Rohingya, Ukraine's third attack on the Crimea Bridge this week, and Denmark's parliament unanimously backing the Greenland security deal with the US.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program copies `entry.png` byte for byte into the output directory and verifies the copy — the picture is the entry, drawn as six captioned panels under the day's date.
